# 🎬 Netflix Data Analysis — End-to-End Analytics Project

An end-to-end data analytics project focused on transforming raw Netflix data into structured information and actionable insights using **Excel, MySQL, SQL, and Power BI**.

![Netflix Dashboard](Netflix_Dashboard.png)

## 📌 Project Overview

This project follows the complete data analytics lifecycle:

**Raw Data → Data Cleaning → Database Design → SQL Analysis → Power BI Dashboard**

The objective was to analyze Netflix's content library and uncover trends across **Movies & TV Shows, release years, countries, categories, directors, and cast members**.

## 🔧 Data Preparation

The raw dataset was cleaned and prepared in **Excel** by:

* Removing duplicate records
* Trimming unnecessary whitespace
* Standardizing blank and missing values
* Preparing data for database integration

## 🗄️ Database & SQL Analysis

The cleaned data was loaded into a structured **MySQL database (`netflix_data`)** and organized into relational tables for titles, cast, countries, directors, categories, and descriptions.

SQL was then used to explore the dataset through:

* Aggregations and filtering
* Grouping and sorting
* Relational joins
* Country and category analysis
* Movie vs. TV Show analysis
* Release-year and content trends

## 📊 Power BI Dashboard

An interactive Power BI dashboard was developed to turn the analysis into an easy-to-explore visual story.

### Key Features

* 🎬 Movies vs. TV Shows analysis
* 📅 Titles added over time
* 🌍 Global content availability map
* 🏷️ Category and genre analysis
* 🎭 Director and cast exploration
* 🔎 Interactive filtering and cross-analysis

## 💡 Key Takeaway

This project highlights that effective data analysis starts **before the dashboard**. Cleaning the data and building a well-structured relational database made the SQL analysis more reliable and the Power BI reporting more meaningful.
